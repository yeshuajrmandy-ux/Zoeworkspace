    🐙 GitHub Integration

    Generate a token at github.com → Settings → Developer Settings → Personal Access Tokens. Needs repo scope.

    🚀 Deploy to Netlify

    Get a token at app.netlify.com → User Settings → Applications → Personal access tokens. Your whole project (all files) will be deployed as a static site.

    ▲ Deploy to Vercel

    Get a token at vercel.com → Settings → Tokens → Create. Your whole project will be deployed as a live site instantly.
